Libro Verifier settings

How pages are verified, and which World Chain endpoints confirm them.

Automatic verification

Chrome will ask to let the extension read every https page. Verification then runs on page load, so a page you visit can cause the extension to fetch the manifest it names and to ask your World Chain endpoints about the signals it claims. Confirmed registrations are cached so the same document is not looked up twice; turning this off clears that cache and hands the permission back.

World Chain endpoints

One endpoint producing the registration event is enough to verify a block. Endpoints that prune old transactions cannot confirm older publications on their own, which is why more than one is queried.

    Added endpoints need permission to be contacted; Chrome will ask when you add one. Custom endpoints must serve World Chain (chain id 480) and support eth_getTransactionReceipt.
